Look at your repo

The repo had only README, LICENSE and .gitignore — so the project is built inside it.

cd ~/ai-web/AI-Web-Quality-Analyzer && git remote -v && ls -A
3

Can PHP see project folders?

Lerd runs PHP in a container. It mounts /home/acquaint at the same path — so the tool can scan any folder in your home.

podman inspect lerd-php85-fpm --format '{{range .Mounts}}{{.Source}} -> {{.Destination}}{{"\n"}}{{end}}'
4

Can PHP reach Ollama on the host?

Test from inside the container: it reaches the host only if the service listens on 0.0.0.0 — that's why Ollama needed OLLAMA_HOST=0.0.0.0 (no longer needed after phase 9).

podman exec lerd-php85-fpm curl -s http://host.containers.internal:11434/api/tags
5

Check Lerd's time limit

Lerd's Nginx waits only 60 s for PHP. Local AI can be slower — so AI work runs in the background after the response.

Start everything with one line

On this computer — after installing native PHP 8.4 and Ollama (developer guide, slides 4 and 6): runs the tests, then starts the app at http://127.0.0.1:8000.

cd ~/ai-web/AI-Web-Quality-Analyzer && /usr/bin/php8.4 artisan test && /usr/bin/php8.4 artisan serve

On a new computer — after the code is pushed to GitHub:

git clone https://github.com/Krunal-gif/AI-Web-Quality-Analyzer.git && cd AI-Web-Quality-Analyzer && composer install && npm install && cp .env.example .env && php artisan key:generate && npm run build && php artisan serve

Turn on the AI (once):

curl -fsSL https://ollama.com/install.sh | sh && ollama pull qwen2.5-coder:3b
